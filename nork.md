# Nork: A Simpler Way to Build Software

Nork is an idea for a meta-tool that uses  AI tools to make managing and writing software projects easier. It doesn't replace Git, Linux, or the tools developers already use. 

It brings them together behind a simpler set of commands that both humans and AI can understand.

Think of Nork as a remote control for your entire coding project.

Instead of memorizing Git commands, navigating folders, managing versions, and figuring out how to push your code to GitHub, you use Nork to manage the whole process.

## How it works

The goal is simple: **spend less time learning commands and managing tools, and more time building software.**

## How It Works

### 1. Create a Project

Create a new project using a simple command, such as `Nork create proj my-app --template svelte`.

Nork creates the project folder locally, generates the Svelte starter files, initializes Git, and prepares a sandboxed development environment.

## The Idea Behind Nork

You shouldn't need to know Linux, Git, Bash scripting, or commands like `grep`, `find`, and `cd` just to build software.

**Nork lets you manage and build coding projects using simple commands and AI.** It handles the underlying tools for you.

### 1. Create a Project

Tell Nork what you want to build. It creates the project and prepares its environment using Docker and existing development tools.

### 2. Let AI Do the Work

Describe what you want to build or change. AI works on your project inside its designated environment. You don't need to manually navigate folders, search files, or write shell scripts.

All you need is an API key for a supported AI model.

### 3. Develop Directly on a Server

You don't necessarily need a local development environment. Nork can manage your projects on a server, where you can develop and test them directly.

For example, `NORK_ENV=dev` identifies the development environment. Other configurations, such as staging or production, can be managed separately.

Each project has its own settings and environment, so you can manage multiple projects without manually configuring everything from scratch.

### 4. Keep the Tools Behind the Scenes

Nork still uses Git for version control, Docker for isolated environments, and Linux tools to manage files and processes. It simply hides much of that complexity behind a consistent interface.

You can still use those tools directly if you want to, but you don't need to master them before getting started.

**The premise is simple: you shouldn't need to learn how the entire computer works just to build an application. Nork handles the development workflow so you and AI can focus on writing and improving code.**
Nork is not a replacement for Git, Linux, Docker, or existing development tools. It is a simple control layer that brings them together into one consistent workflow.

By building on proven tools, Nork can help beginners start coding without first mastering every command, while allowing experienced developers to keep using the tools they already know.

## Why Nork?

Learning to code is already difficult. Beginners shouldn't have to master every detail of Git, Linux, and development workflows before they can start building useful software.

Nork builds on the tools that already work. It adds a simpler layer on top of them, so developers and AI can manage an entire coding project through one consistent interface.

The underlying tools remain accessible. Experienced developers can still use Git and their usual terminal commands whenever they want.

**Nork is a meta-framework for managing and building software with AI.** It simplifies the workflow without reinventing the tools underneath.

The goal is to make software development more accessible: initialize a project, connect an AI model using an API key, and start building.
